# Sweta Rai

PhD Candidate in Bioinformatics, University of Lethbridge

I work on multi-omics analysis and biomarker discovery for rheumatoid arthritis, integrating transcriptomic and methylomic data with machine learning to identify sex-stratified, treatment-responsive biomarkers. My work spans differential expression analysis, multi-omics data integration (horizontal and vertical), feature selection, and predictive modelling — plus building the R/Shiny tools that make that analysis usable by others in the lab.

- **Research focus:** multi-omics integration · biomarker discovery · rheumatoid arthritis · differential gene expression · synthetic data generation (GANs)
- **Tools:** R (Bioconductor, DESeq2, Shiny), Python (scikit-learn, XGBoost, pandas), Boruta, GEO/NCBI data pipelines
- **Background:** Gold Medal, MSc, Bangalore University (2022) · Data Science Engineer, SirpiData Science (IISc Bangalore-affiliated project) · Certified Data Scientist
